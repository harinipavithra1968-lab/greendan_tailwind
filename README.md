Greendan

Greendan is a simple and responsive plant shopping website built using HTML and Tailwind CSS.

 About

This project is a frontend website for a plant store. It includes a home page, products page, and contact page with a responsive design for mobile and desktop screens.

 Features

- Responsive navigation bar
- Home page with plant information
- About Us section
- Best Seller section
- Product listing page
- Product search input
- Customer Reviews section
- Newsletter subscription section
- Contact form
- Responsive design using Tailwind CSS
- Hover effects on product images

 Technologies Used

- HTML5
- Tailwind CSS
- SVG Icons
- Responsive Design

 Pages

- Home – Introduction, about, best sellers, reviews and newsletter
- Products – Displays available plants and prices
- Contact – Contact form for users
